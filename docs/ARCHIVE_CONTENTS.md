# 归档范围

本仓库存放上一轮已确认交付包的展开文件，包含三套主图、独立生成终版素材、透明分层、提示词、制作记录和之前明确认可的替代服装。以三个角色主目录的manifest.json为定稿依据。

重复的总ZIP、角色ZIP和素材ZIP不重复写入Git历史。所有内容以文件展开存档，可用GitHub的Code → Download ZIP取得。原交付包仍在本地保存；本仓库的逐文件SHA-256支持完整性检查。

历史制作记录中的本地源路径或待确认状态反映当时过程，不覆盖此次最终确认。仓库提交不包含密码、访问令牌、账户登录资料或原始会话记录。

许可证与署名说明位于LICENSE、NOTICE.md、LICENSES/和docs/ASSET_SOURCES.md。
